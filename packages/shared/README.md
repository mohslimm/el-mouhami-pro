# @el-mouhami/shared

## Présentation
Package partagé contenant la logique métier commune aux clients Desktop et Mobile :
- Règles et délais de procédure civile et administrative algérienne (CPCA, articles 405/406).
- Schémas Zod pour validation des données côté client.
- Interfaces TypeScript et modèles de contrats/dossiers.
