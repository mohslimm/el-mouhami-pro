# El-Mouhami Pro — Backend & Infrastructure Souveraine

## Présentation
Ce répertoire centralise les schémas de base de données, les migrations SQL et les services serveurs pour l'instance Supabase auto-hébergée (VPS Algérie Télécom).

## Structure
- `supabase/migrations/` : Scripts de migration SQL (tables, RLS policies, triggers, vues)
- `scripts/` : Scripts d'automatisation (backups pg_dump, rotation des clés)

## Conformité Loi 18-07 & Secret Professionnel
- Hébergement physique garanti sur le territoire national algérien.
- Politiques strictes de Row Level Security (RLS) garantissant le cloisonnement étanche entre cabinets.
